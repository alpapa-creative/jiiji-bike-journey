# じいじのバイク旅（公開デモ版）

ギフトゲーム事業の出品ページに載せる「実際に贈った事例」の匿名化デモ。
元プロジェクトは `02_game/じいじのバイク旅`（**元は変更禁止。修正はこのコピーで行う**）。

瀬戸内の「じいじの家」から湘南の「孫たちの家」まで100kmを走る横スクロールバイク旅ゲーム
（デモ版のため元の848kmから短縮。加速カーブ・応援メッセージ・ゴール演出も100kmに再スケール済み）。

## 起動方法

- `index.html`（→ `code_artifact.html` へリダイレクト）をブラウザで開くだけで動く（file:// 可）
- プレビューは `node dev-server.cjs` → http://localhost:8767/ （launch.json 登録済み・ポート台帳 8767）

## 画面構成

- タイトル画面: BGMモード選択（ノリノリ / しんみり）→ 出発
- ゲーム画面: タップ/クリック/Spaceでジャンプ（2段ジャンプ対応）。障害物=コーン・バリケード・カラス・イノシシ、回復=おにぎり・瀬戸内みかん・静岡茶
- リザルト: ゴール到着 / リタイア

## 設定の所在

- 画像: `code_artifact.html` 内 `IMAGE_SOURCES`（未設定時はCanvasベクター描画にフォールバック）
- BGM: 同 `BGM_SOURCES` / `BGM_VOLUME`
- その他ゲーム調整値は `code_artifact.html` 内（元プロジェクト由来のため冒頭CONFIG集約はされていない）

## 仮設定にした項目

- 架空の地名「瀬戸内/湘南」は仮決め（変更容易: 上記の置換系統のみ）
- じいじ・こどもたちのイラストは本人判断で**そのまま使用でOK**（2026-07-13確認済み）
- **BGMは差し替え済み**（2026-07-13）: 元の歌入り2曲は歌詞に「鎌倉まで」があったため削除し、
  自作チップチューンのインスト2曲（`bgm-nori.mp3` 152BPM / `bgm-shinmiri.mp3` 76BPM、
  numpy合成・完全自作でライセンスクリーン）に置換。曲の再生成は
  `tools/make_bgm.py`（numpy必須。wav出力後ffmpegでmp3化）（要調整ならテンポ・メロディ配列を変更）
- 曲の雰囲気は仮決め（本人の耳での確認待ち）
